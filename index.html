Tapa · 八邻环分段推理

数字写着黑格在你周围八格里怎么长，一段一段从正北顺时针数过去

带数字的那一格自己就是黑的。它周围的八格连成一个环，数字按顺时针读：先数北边那一段有多长， 再数下一段。2 1 就是说环上有两段黑格，一段两格、一段一格，中间至少隔一格白。 0 0 0 是一句实打实的证词：这一格是白的，它周围八格也全是白的——它和"这里没数字"是两回事， 画面上也不一样（三个青色零，外加一圈虚线环）。 黑格不能凑满一个二乘二，白格必须连成一整片。 这里没有运气题：每一局都只有一个答案，也每一局都能靠逻辑推到底。

    你会用到的五条规则

    1. 线索自黑：写着数字的那一格，自己就得染黑。
    2. 环上相容：八格里已有的黑段必须能拼成那几组数字——拼不成的排法整条划掉。
    3. 二乘二禁：任何二乘二里不能四格全黑，所以三格已黑时第四格必白。
    4. 白格连通：白格是一整片，谁也不能被黑格围死在一角。
    5. 反证排除：假定某一格是黑，若无论如何都推不出答案，它就只能白。

    五条都只读盘面自己的账：它们写下的每一格，在盘面的每一个解里都成立—— 所以提示永远不需要猜。这两件事由 node tools/engine-test.mjs 与 npm run balance 在命令行里逐条断言。
